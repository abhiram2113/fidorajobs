# FidoraJobs Marketing Website

Standalone static, multi-page marketing website for Indian job seekers.

## Pages
- `index.html` — home and promotional overview
- `discover.html` — recent jobs and official career-link value proposition
- `features.html` — overview, discovery, resume insights, application tracking, support and lifetime access
- `pricing.html` — one-time lifetime plans and FAQs

## Deploy
Deploy the `marketing` directory as the Vercel project's root directory, using the `Other` framework preset and no build command. Add the chosen subdomain to that Vercel project. The mock job cards are illustrative and must not be represented as live job results.

## Pricing shown
- Individual: ₹499 total for 1 member
- Duo: ₹299 per member / ₹598 total for 2 members
- Friends referral: ₹99 per member / ₹297 total for 3 members

The marketing page links plan enquiries to support@fidorapath.in. Replace those enquiry links with a verified checkout/payment flow before taking online payments.
